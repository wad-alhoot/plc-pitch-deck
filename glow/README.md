# GLOW — الموقع الإلكتروني الرسمي

موقع **GLOW** (استوديو ذكاء اصطناعي وأتمتة — الرياض): صفحة واحدة، عربية RTL،
بتصميم **زجاجي (Glassmorphism)** متحرك مبني بالكامل فوق
[GLOW Brand System v1.0](#المرجع-البصري).

> نبني أنظمة ذكية، لا جهداً أكبر.

---

## نظرة سريعة

| | |
|---|---|
| **التقنية** | HTML5 + CSS3 + JavaScript صرف — بدون أي إطار عمل أو خطوة بناء |
| **الحجم** | ثلاثة ملفات مصدر (`index.html` · `style.css` · `main.js`) + الأصول |
| **الاعتماديات** | لا شيء وقت التشغيل. الخطوط فقط من Google Fonts |
| **الاتجاه** | RTL عربي، مع طبقة Mono إنجليزية UPPERCASE حسب دليل الهوية |
| **النشر** | ملفات ثابتة — GitHub Pages / Netlify / Vercel / أي استضافة |

## التشغيل محلياً

```bash
git clone https://github.com/<owner>/glow.git
cd glow
python3 -m http.server 8000     # أو: npx serve .
```

ثم افتح <http://localhost:8000>.

لا يوجد `npm install` ولا خطوة بناء — الملفات جاهزة كما هي.

## المؤثرات البصرية والتفاعلية

**الطبقة الخلفية**

- أربع كتل ضوئية (Aurora) بألوان الهوية الأربعة، تتحرك ببطء بمسارات مختلفة
- شبكة مخطط هندسي (Blueprint Grid) تنزلق باستمرار مع قناع تدرّجي
- **Pixel Field** على `<canvas>`: جسيمات مربّعة مُثبّتة على شبكة 4px، تكبر وتتصل
  بخطوط ضوئية عند اقتراب المؤشر
- طبقة ضوضاء (Noise) خفيفة تمنع تكوّن أشرطة التدرّج

**الزجاج**

- `backdrop-filter: blur(26px) saturate(150%)` مع طبقة لمعان (Sheen) مائلة
- إضاءة موضعية تتبع المؤشر داخل كل بطاقة (`--mx` / `--my`)
- زوايا شبه قائمة (2–6px) — البكسل هو الهوية، لا الزوايا الدائرية

**الحركة**

- ظهور تدريجي عند التمرير (IntersectionObserver)
- عدّادات رقمية بتسارع `easeOutCubic`
- إمالة ثلاثية الأبعاد للوحة الـ Hero + أزرار مغناطيسية
- هالة تتبع المؤشر بحركة تنعيم (lerp)
- تركيب شعار البكسل خلية بعد خلية
- شريط تقدّم التمرير أعلى الصفحة

**إمكانية الوصول**

- `prefers-reduced-motion` يُعطّل كل الحركة والـ canvas والهالة
- `:focus-visible` واضح بلون الهوية السماوي
- تباين نصوص مضبوط في الوضعين الليلي والنهاري
- تسميات `aria-label` على كل زر أيقوني، و`aria-expanded` على القائمة

## الوضع الليلي / النهاري

الافتراضي **ليلي** (هوية الموقع). يبدّل الزائر عبر زر القمر/الشمس في الشريط العلوي،
ويُحفظ الاختيار في `localStorage` تحت المفتاح `glow-theme`.
تفضيل النظام لا يتجاوز الافتراضي — فقط اختيار صريح سابق من الزائر.

## المرجع البصري

كل قيمة في الموقع مشتقة من **GLOW Brand System v1.0**:

| العنصر | القيمة |
|---|---|
| السماوي | `#29ABE2` |
| الأحمر | `#ED1C24` (تنبيه فقط) |
| البرتقالي | `#F7941E` |
| البنفسجي | `#92278F` — لون الهوية الأساسي |
| البنفسجي الغامق | `#6E1D6C` |
| الحبر | `#141317` → `#F5F5F7` (سلّم بارد) |
| الخط العربي | IBM Plex Sans Arabic (300–600) |
| الخط الآلي | IBM Plex Mono (400–500) |
| وحدة المسافات | 4px — كل القيم مضاعفاتها |
| الوزن 700 | **محظور** |

**ملاحظة على المظهر الزجاجي:** دليل الهوية الأصلي يمنع الظلال والتدرّجات ويفرض
زوايا صفرية، لأنه مكتوب لمخرجات مطبوعة. الموقع يبقى وفياً للنظام في اللون والخط
والمسافات وشبكة البكسل والطبقة الآلية Mono، لكنه يستخدم الزجاج والتدرّجات
والإضاءة كطبقة **شاشة** مطلوبة صراحةً لهذا المخرج — مع إبقاء الزوايا شبه قائمة
حتى لا يفقد البكسل حدّته.

## التخصيص

**الألوان** — عدّل المتغيرات في `:root` أعلى `assets/css/style.css`.

**المحتوى** — كل النصوص داخل `index.html` مباشرة، بلا نظام قوالب.

**بيانات الاتصال** — ابحث عن `info@glows.studio` و`966573997668` في
`index.html` و`assets/js/main.js` واستبدلها.

**نموذج التواصل** — يعمل حالياً عبر `mailto:` (لا يحتاج خادماً). لربطه بخدمة
حقيقية، استبدل معالج `submit` في القسم 15 من `assets/js/main.js` بطلب `fetch`
إلى Formspree أو Web3Forms أو دالة سحابية خاصة بك.
