# فارما قولد كير — الهوية البصرية (PGC Brand Kit)

مرجع مختصر للهوية المعتمدة في موقع `pharmagold-care` بعد إعادة التصميم.

## الشعار

`pgc-logo-mark.svg` — كبسولة رأسية مفتوحة بداخلها مونوغرام **PGC** متداخل:

| العنصر | الوصف | اللون |
|---|---|---|
| الكبسولة | مستطيل بزوايا نصف دائرية `rx=110` | تيل `#1F4A44` |
| P | ساق رأسية طويلة + بطن علوي | تيل `#1F4A44` |
| G | قوس أوسط مع عارضة أفقية | ذهبي `#B5904E` |
| C | قوس سفلي كبير مفتوح جهة اليمين | تيل `#1F4A44` |

- على الخلفيات الداكنة: خطوط التيل تصبح عاجية `#F4F2EC`، ويبقى الـ G ذهبيًا.
- الشعار اللفظي: `PHARMA GOLD CARE` — كلمة `GOLD` وحدها بالذهبي.
- الشعار النصي: «رعاية بمعيار ذهبي».

## الخطوط

- العربية والواجهة: **IBM Plex Sans Arabic** (الجسم 300، العناوين 600).
- الأرقام والنصوص اللاتينية: **IBM Plex Mono** داخل أداة `mono` مع `direction: ltr; unicode-bidi: isolate`.

## لغة التصميم

داكن أولًا · زجاجي (glassmorphism) · أورورا ضبابية متحركة · شبكة blueprint · حقل جزيئات تفاعلي على canvas · كشف عند التمرير · أزرار مغناطيسية · بطاقات ببقعة ضوء تتبع المؤشر · عدّادات أرقام · لودر افتتاحي. الزوايا حادة (2–6px). كل حركة تحترم `prefers-reduced-motion`.
